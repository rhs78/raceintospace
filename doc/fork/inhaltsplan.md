### Missionsarten für Sonden

| Missionsart | Ziele | heute im Spiel |
|---|---|---|
| Erdsatellit (Forschung, Wetter, Kommunikation, Aufklärung) | Erde | nur „Orbital Satellite“ |
| Einschlag / harte Landung | Mond | – |
| Vorbeiflug | Mond, Venus, Mars, Merkur, Jupiter, Saturn, Kometen | ja (vereinfacht) |
| Orbiter | Mond, Venus, Mars | – |
| weiche Landung | Mond, Venus, Mars | nur „Lunar Probe Landing“ |
| Rover | Mond (später Mars) | – |
| Probenrückführung | Mond | – |
| Atmosphärensonde | Venus, Jupiter | – |

Dazu gehören: Startfenster je Planet (seit Etappe 3 berechnet), Flugzeit über mehrere Runden,
Ausfallrisiko während des Flugs, **Wissenschaftswert** zusätzlich zum Prestige und neue
„Erste“-Kategorien (erstes Bild der Mondrückseite, erste weiche Landung, erster Orbiter usw.).
Die Mechanik dafür ist Etappe 9; Ausbaustufe 1 nutzt zunächst die vorhandenen Missionsarten
(Satellit, Mondvorbeiflug, Mondlandung, Venusvorbeiflug) plus Einschlag.

## 2. Folgen für den Hardware-Katalog (Etappe 4c)

Damit diese Programme später ohne erneuten Umbau passen, nimmt Schritt 4c folgende Punkte
in das Datenmodell auf:

| Bedarf | Programme | Katalog |
|---|---|---|
| Raumgleiter mit Landung auf einer Piste, Fluggerät wird nicht verbraucht | X-15, Dyna-Soar, MiG-105 | Rolle `spaceplane`, `consumed_on_flight: false`, Lebensdauer in Flügen |
| Start ohne Rakete (Abwurf vom Trägerflugzeug) | X-15, MiG-105 (Testflüge) | `launch_mode: air_launch`, Trägerflugzeug als Infrastruktur statt Rakete |
| Start auf einer Rakete | Dyna-Soar | `launch_mode: rocket` (Standard) |
| Labor an einer Kapsel | MOL (Gemini B + Labor) | Rolle `lab_module`, Paarung wie beim Mondlander (`compatible_labs`) |
| Raumstation als dauerhaftes Objekt im Orbit | Skylab, Saljut, MOL | Rolle `station`, Lebensdauer, Crew-Plätze, Andockstellen; **Spielzustand „Objekte im Orbit“** |
| neue Missionsarten | alle | z. B. „Raketenflugzeug-Höhenflug“, „Raumgleiter-Orbitalflug“, „Station starten“, „Crew zur Station“, „Langzeitaufenthalt“ – Missionsdaten ab Etappe 5 |
| neue Prestige-Kategorien | z. B. erster geflügelter Raumflug, erste Raumstation, erste weiche Landung | Prestige-Liste wird mit 4c erweiterbar |
| Sondentypen und Ziele | alle Raumsonden | Rolle `probe` mit `probe_type` (Satellit, Einschlag, Vorbeiflug, Orbiter, Lander, Rover, Probenrückführung, Atmosphäre) und `targets` (Erde, Mond, Venus, Mars …) |
| Satellitenzweck | Tiros, Echo, Telstar, Corona | `satellite_purpose` (Forschung, Wetter, Kommunikation, Aufklärung) |

Die **Station als dauerhaftes Objekt** ist der aufwendigste Teil (eigener Spielzustand,
Versorgung, Alterung). Er gehört inhaltlich zu Etappe 10; 4c legt nur die Datenstruktur an.
